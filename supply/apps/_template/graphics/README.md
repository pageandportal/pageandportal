# Graphics for this app

Add image files here. Suggested names (rename if you prefer):

| File | Purpose |
|------|---------|
| `logo.svg` or `logo.png` | Square or icon logo |
| `hero.webp` or `hero.png` | Wide banner (~1200×600 or similar) |
| `feature-1.png`, `feature-2.png`, … | Screenshots referenced in `app.md` |

**Formats:** PNG, WebP, or SVG preferred.  
**Alt text:** Describe each image in `app.md` (agents use this for accessibility).

If you have no artwork yet, say so in `app.md` under **Graphics checklist** — do not leave this folder empty without that note.
