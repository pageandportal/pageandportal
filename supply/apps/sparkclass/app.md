## Features

### Feature 1 — Class-gated learning

- **Title:** Built around your class
- **Description:** Students join with an invite code. Practice, live sessions, and Q&A stay inside the class boundary — trainers see their roster and per-student progress; peers see only what they should.
- **Image (optional):** —

### Feature 2 — Topic practice

- **Title:** Practice by unit-standard topic
- **Description:** Drill quizzes mapped to NZ electrical training topics — multiple choice, true/false, numeric and guided recall, plus parametric maths that generates fresh values for each attempt.
- **Image (optional):** —

### Feature 3 — Live sessions

- **Title:** Live class sessions
- **Description:** Trainers host live quiz sessions with a PIN join code, timed questions, and a class leaderboard — built for tablets and phones in the room.
- **Image (optional):** —

### Feature 4 — Class Q&A

- **Title:** Ask without the spotlight
- **Description:** Class Q&A with an optional anonymous mode for peers. Trainers moderate pins and replies; identity on anonymous posts stays hidden until an intentional Reveal for moderation (audit-logged).
- **Image (optional):** —

### Feature 5 — Explore further

- **Title:** Explore when you get stuck
- **Description:** Keyword links and an Explore handoff open Gemini or ChatGPT with a prefilled prompt — helpful after a wrong answer or skip, without putting AI keys in the learner’s browser.
- **Image (optional):** —

### Feature 6 — Trainer tools

- **Title:** Trainer console
- **Description:** Invite-only trainer accounts, class roster, progress overview, live hosting, and Q&A moderation — with a primary admin trainer who can approve additional tutors.
- **Image (optional):** —
