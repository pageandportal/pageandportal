features:
  - title: Built around your class
    description: >-
      Students join with an invite code. Practice, live sessions, and Q&A stay
      inside the class boundary — trainers see their roster and per-student
      progress; peers see only what they should.
  - title: Practice by unit-standard topic
    description: >-
      Drill quizzes mapped to NZ electrical pre-trade topics — multiple choice,
      true/false, numeric and guided recall, plus parametric maths that generates
      fresh values for each attempt.
  - title: Live class sessions
    description: >-
      Trainers host Kahoot-style sessions with a PIN join code, timed questions,
      and a class leaderboard — built for tablets and phones in the room.
  - title: Ask without the spotlight
    description: >-
      Class Q&A with an optional anonymous mode for peers. Trainers moderate pins
      and replies; identity on anonymous posts stays hidden until an intentional
      Reveal for moderation (audit-logged).
  - title: Explore when you get stuck
    description: >-
      Keyword links and an Explore handoff open Gemini or ChatGPT with a
      prefilled prompt — helpful after a wrong answer or skip, without putting AI
      keys in the learner’s browser.
  - title: Trainer console
    description: >-
      Invite-only trainer accounts, class roster, progress overview, live hosting,
      and Q&A moderation — with a primary admin trainer who can approve additional
      tutors.
